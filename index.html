01About

The math decides when to stop, not the model's confidence.

Retrieval scores over self-reported certainty. Pruned weights over bloated checkpoints. Shipped code over benchmark screenshots.

Lately that means going one layer down: writing the scheduler instead of calling generate(), and writing the autograd instead of importing it. It's slower. It's also the only way I've found to actually understand the thing.

BIT Mesra, studying what doesn't fit in a lecture hall. I write up everything I build, and I'm always maintaining unbroken eye contact with a single code block like we have beef.

    LLM inference & serving

    ★ 97 ⑂ 10

    PageServe

    A vLLM-style inference engine, grown from a naive generate() loop in 11 phases.

    Continuous batching, a paged KV cache over a physical tensor pool, prefill/decode budgets, and CPU swap so it degrades under load instead of OOMing. Also found and fixed a cache bug costing 1.1 ms per token.

    ★ 11

    RLForge

    A reinforcement-learning library with no import torch, down to its own autograd.

    Tensor engine, autograd, optimizers, Q-learning, DQN and PPO in C++20 with zero dependencies, including the diamond-graph gradient case most from-scratch engines silently get wrong.

    Environments, tensor/autograd and DQN by me. PPO, threading and CUDA/BLAS backends co-built with aprv10.

    Multi-agent systems

    GitHub ↗

    HiveMind

    Can a research system know its own answer isn't good enough, and fix it?

    A 5-agent pipeline (Planner → Researcher → Critic → Writer → Evaluator) that loops until a deterministic confidence threshold is met, computed from mean retrieval score, not the LLM's self-report.

    FastAPI · Redis · ChromaDB · OpenTelemetry · Docker

    Developer tools

    Demo ↗GitHub ↗

    CodeLens

    Can you search a codebase by intent, not keywords, fully offline?

    A VS Code extension that chunks code by AST with tree-sitter, embeds it locally through Ollama, and jumps you to the exact line from a plain-English query. No internet, no API keys.

    TypeScript · tree-sitter · Ollama · VS Code API
